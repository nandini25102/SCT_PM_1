# Task 01: User Persona & Empathy Map

## 📌 Objective

The objective of this task is to understand the target users by creating a detailed User Persona and an Empathy Map for a selected real-world problem.

Understanding user behavior, motivations, frustrations, and goals before building a product helps product managers create user-centric solutions that solve real problems effectively.

---

## 📝 Problem Statement

**Difficulty Finding Parking in Cities**

Urban commuters often spend a significant amount of time searching for available parking spaces. This leads to unnecessary traffic congestion, fuel wastage, increased pollution, and stress among drivers.

The goal is to understand the users affected by this problem and identify opportunities for building a better parking experience.
